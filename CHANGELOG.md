# Changelog

## 1.0.0

- Screen orientation control for .NET MAUI on iOS and Android
- `Orientation.Lock(...)`, `Unlock()`, `SetAsync(...)`, `Changed`
- Nested lock stack and per-page `Orientation.Preferred` / `Bind`
- Optional `UseDeviceOrientationPlus` host registration
- Sample (video landscape, scanner portrait) and unit tests
